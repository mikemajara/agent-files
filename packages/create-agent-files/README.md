# create-agent-files

Scaffold an [Agent Files](https://github.com/mikemajara/agent-files) app.

```bash
npx create-agent-files@latest my-app
npx create-agent-files@latest my-app --storage vercel
npx create-agent-files@latest my-app --storage local -y
```

Storage options: `vercel` (default), `r2`, `local`.
