# Weekly plan

1. Observer: read the plot log and hand the planner rows with plot label, date, observable condition, and uncertainty. If you cannot read the log, send that status instead of inventing observations.
2. Planner: take those rows and propose tasks grouped by plot; tie each task to its observation. If the handoff is missing or incomplete, list what needs checking and mark any affected task provisional. Return the plan and open questions; do not write to the plot log.
