## Problem and goal

Check whether the minimum format generalizes beyond its first example without accumulating assumptions from one application or use case.

## In scope

1. Describe two standalone agents in a synthetic community garden package under `examples/community-garden`. Use the existing format and reuse the same example to test [tools](./4.md) and [routines](./5.md).
2. Record missing descriptive concepts, unnecessary mandatory fields and application-specific assumptions revealed by the second example.

## Exclusions

Live installation, runtime import/export, execution demonstrations and adding fields merely to mirror a destination app.

## Acceptance criteria

1. A second-domain example describes agent purpose, behavior, resources, connections, routines and relationships with the core format.
2. Each proposed format change has a concrete descriptive gap demonstrated by the example.
3. Original sources remain intact and the package contains no runtime state, credentials or application IDs.

## Verification scenarios

1. **AC 1** — Given the first format and second-domain example, a reader follows the same entry path and explains both agents and their routine handoff without application context.
2. **AC 2** — Compare each proposed change to the example and identify the missing fact it expresses; reject changes with no demonstrated need.
3. **AC 3** — Compare selected source hashes before/after authoring and inspect the example for state, credentials and application-generated identities.

## Constraints

Follow-up only after the small first version. Preserve domain neutrality and existing sources. No target system or installation capability is a prerequisite.

## Findings and open questions

Use plot observations and garden planning as the second domain. Include instructions, one fictional memory, a shared skill and tool, and an inactive weekly routine with two participants. Summarize what the current format could express, and call out limitations without proposing an extension that the example did not require. No real source files or services are used.
