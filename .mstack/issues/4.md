## Problem and goal

Describe what an agent should be able to use and connect to without specifying the system that provides or installs it.

## In scope

1. Refine the simple tool/integration references established by [1](./1.md) when real examples reveal a missing descriptive field.
2. Record capability or service name, purpose, relevant usage expectations and optional technical connection information. MCP may be one optional mechanism.
3. Keep shared integration definitions independent of agent assignments.

## Exclusions

Installers, authentication flows, provider adapters, sandbox policy and live connection diagnostics.

## Acceptance criteria

1. A reader identifies what each selected agent needs and why from its references and the shared definitions.
2. An integration can be described without MCP; optional mechanism details do not change the core agent identity or skill procedure.
3. References work for shared and unassigned definitions and contain no credential values or application-generated IDs.

## Verification scenarios

1. **AC 1** — Read the selected agent and follow its integration references; explain the capability/service, purpose and expected use using only those files.
2. **AC 2** — Compare a mechanism-neutral integration with an example containing optional MCP details; both express the same intended connection without introducing application requirements.
3. **AC 3** — Resolve shared and unassigned examples and inspect their fields for secret values and app-generated identities.

## Constraints

Follow-up descriptive refinement after the minimal v0.1 example, only where evidence warrants extra structure. Preserve sources. The core vocabulary is tools/integrations rather than a transport protocol.

## Findings and open questions

Use the synthetic community garden example in [7](./7.md) to show one shared, mechanism-neutral reading capability and an unassigned illustrative MCP alternative for the same purpose. Use existing tool descriptions and optional config with no authentication, runtime setup or schema change.
